Description

Dayan.ProofGen.Jacobian — CRT 行列式证明项生成器

从 dype O(1) 计算结果生成 Agda 证明项: det M ≡ result 的证明 = refl (因为 dype 已计算完毕)

对齐: jac_CRTDet.agda: det(M) ≠ 0 ⟺ det(M₃) ≠ 0 ∧ det(M₄) ≠ 0 jac_NMatrix.agda: DetNonzero ⟺ NoZeroRow ∧ ColDistinct ⟺ 双射

策略: dype 做 O(1) 计算, 生成 refl 证明项让 Agda 验证
